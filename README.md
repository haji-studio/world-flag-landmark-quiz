# World Flag & Landmark Quiz

어린이와 학생을 위한 **세계 국기 & 랜드마크 퀴즈 게임**입니다.

국기를 보고 나라를 맞히고, 세계 유명 랜드마크를 보며 어느 나라에 있는지 배울 수 있는 교육형 웹게임입니다.

## 🎮 주요 기능

- 국기 보고 나라 맞히기
- 랜드마크 보고 나라 맞히기
- 쉬움 / 보통 / 어려움 난이도
- 한국어 / 영어 / 중국어 지원
- 오늘의 도전 10문제
- 정답 / 오답 자동 진행
- 틀린 문제 복습
- 결과 화면 칭호 시스템
- 문제 음성 읽기 기능
- 모바일 반응형 화면

## 🌍 게임 모드

### 국기 퀴즈
화면에 나오는 국기를 보고 어느 나라의 국기인지 맞히는 모드입니다.

### 랜드마크 퀴즈
세계 유명 랜드마크 사진을 보고 어느 나라에 있는지 맞히는 모드입니다.

### 오늘의 도전
매일 새로운 10문제를 풀 수 있는 데일리 퀴즈 모드입니다.

## 🧒 추천 대상

- 초등학생
- 세계 나라와 국기를 배우는 아이들
- 가족이 함께 즐기는 교육 게임
- 한국어, 영어, 중국어로 나라 이름을 배우고 싶은 사용자

- LocalStorage
